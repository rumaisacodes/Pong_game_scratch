# 🏓 Scratch Pong Game

Welcome to the **Scratch Pong Game** repository! This is a modern take on the classic arcade game, built using Scratch. It features fast-paced gameplay, smooth controls, and an automated scoring system to track your high scores.

## 🚀 Play the Game

## 🎮 How to Play

The objective is simple: keep the ball in play and don't let it slip past your paddle!

*   **Move Left / Right:** Use your mouse pointer (or the arrow keys) to control the paddle.
*   **Bounce:** Hit the ball with your paddle to bounce it back up.
*   **Score:** Every successful bounce increases your score. 
*   **Game Over:** If the ball touches the red line at the bottom, the game ends!

---

## ✨ Features

*   **Smooth Controls:** Responsive paddle movement for a classic arcade feel.
*   **Dynamic Ball Physics:** The ball bounces realistically off the walls and the paddle.

---

## 📝 About the Project

This project was created to explore game development logic, variable management, and collision detection using Scratch's visual block programming language. 

Feel free to fork this repository, add new features (like a two-player mode or power-ups), and make it your own!
